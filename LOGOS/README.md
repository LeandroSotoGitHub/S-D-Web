# LOGOS — S&D Sostenibilidad y Desarrollo de Negocios

Logos en alta calidad, redibujados en vector a partir de `img/logo.png` (octubre 2026).

## Carpetas

| Carpeta | Formato | Para qué |
|---|---|---|
| `SVG/` | Vector **en curvas** (sin fuentes) | Web, imprenta, cartelería, corte de vinilo, bordado. Es el archivo maestro. |
| `PDF/` | Vector | Imprentas y programas de diseño (Illustrator, InDesign, Affinity). |
| `PNG/` | 5000 px, fondo transparente | Word, PowerPoint, Canva, redes. |
| `FAVICON/` | `favicon.ico` + PNG 16–512 px | Pestaña del navegador, ícono en celulares, avatar. |

## Versiones

- `isotipo-color` — versión principal, sobre blanco o beige claro.
- `isotipo-negativo-sobre-borgona` — para fondos borgoña (el arco borgoña pasa a beige claro).
- `isotipo-mono-borgona`, `isotipo-mono-negro`, `isotipo-blanco` — un solo color (sellos, grabados, fotos).
- `logo-horizontal-*` — isotipo + "Sostenibilidad y Desarrollo de Negocios" (Cormorant Garamond).
- `logo-vertical-*` — isotipo + bajada en Jost mayúsculas.

## Qué se cambió respecto del original

- Formas de los arcos trazadas en curvas y suavizadas, sin cambiar su forma ni posición.
- Colores llevados exactamente a la paleta oficial: borgoña `#7A1E2C`, beige arena `#E8D8C3`, verde oliva `#6F6A49`.
- Se quitaron las sombras y degradés que tenía la imagen original.
- Las letras "S&D" se reconstruyeron con **Libre Caslon Text** (Google Fonts, licencia OFL), la serif que mejor coincide con el dibujo original, ajustada a la misma caja de cada letra. Están convertidas en curvas: no hace falta instalar la fuente.

Reglas de uso (resguardo, tamaños mínimos, usos incorrectos): ver el **Manual de marca** en `MARCA/`.
